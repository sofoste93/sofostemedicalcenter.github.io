# Changelog

## 2.0.0 — 2026-10-03

- Rebuilt the prototype as an installable Python package with a responsive green-and-white interface.
- Replaced disk-based shared state with stateless, in-memory encrypted packets.
- Separated the QR packet from its high-entropy transfer key.
- Added French, English and German, help, display settings and trusted-LAN mode.
- Added security headers, CSRF protection, input limits and failed-decryption throttling.
- Added automated tests and portable releases for Windows, Linux and macOS.
